# CodingClerks Launchpad

Create Phase 1 of CodingClerks, a premium agentic SaaS web app builder.

Only implement the brand system, shared marketing components, and public landing page. Do not build backend integrations.

CodingClerks turns product prompts or public URLs into working React applications using AI coding agents, Firecrawl, isolated sandboxes, live preview, GitHub export, and Vercel deployment.

Brand:

- Near-black #07090D background

- #0D1016 elevated surfaces

- Electric green #B8FF5A primary accent

- Ultraviolet #7867FF secondary accent

- Warm-white #F3F1E8 text

- Geist Sans and Geist Mono

- Premium futuristic coding bureau, precise and editorial

- Fine grid, restrained blooms, ledger/status motifs

- No Lovable branding, no cartoon robot, no generic neon cyberpunk

Create:

- CodingClerks wordmark and compact command-style symbol using CSS/SVG

- Global design tokens

- Header and responsive navigation

- Hero: “Your coding desk, staffed by agents.”

- Prompt/URL builder demonstration

- AI clerk activity ledger and live preview illustration

- Product capabilities

- Workflow

- Animated and interactive website specialization

- Coding Points teaser

- Security/code ownership section

- Pricing teaser

- Final CTA and footer

- Full mobile, tablet, and desktop behavior

- Reduced-motion support

Use Next.js, TypeScript, React, and Tailwind. Generate merge-friendly presentational components. Do not create production API routes or add secrets. Finish by listing every changed file.
