# Sonnygames

A sports-car learning game for Sonny (age 3).

- **ABC Race** - hear a letter, tap the matching car, race to the finish. Starts with S-O-N-Y, then CAR, then the rest; later asks for little letters too. Says each letter's sound and an example word.
- **Word Garage** - a picture clue plus letter tiles: tap the letters in order to spell CAR, BUS, SUN, SONNY...
- **Count Cars** - tap each coloured car to count it out loud, then pick the number. Teaches colours too.
- **My Cars** - stars earned unlock 12 sports cars to collect and drive.

It adapts: answers right first try raise mastery, misses repeat sooner, and new letters/words/bigger numbers unlock gradually. Progress is saved in the browser (localStorage). Press and hold the lock at the bottom of the home screen for the grown-ups panel (progress, sound toggle, reset).

Voice uses the browser's text-to-speech and sounds are synthesised, so there are no audio files.

## Voice

Everything Sonny John hears is a pre-recorded human-sounding voice clip (one clip per sentence,
230 in all), always using his full name. The text for every clip is in `src/lib/voice-lines.ts`.
Where the clips live is in `src/lib/voice-manifest.ts` (generated by
`node scripts/make-voice-manifest.mjs` from `scripts/voice-clips.txt`). If a clip cannot load, the
browser voice reads the same words so the game never goes quiet.

To host the clips inside the app instead of linking to them: save each as `public/voice/<key>.mp3`
and set `VOICE_LOCAL = true` in `scripts/make-voice-manifest.mjs`, then re-run it.

## Games

ABC Race, Word Garage, Count Cars, Parking Lot (park exactly N cars), More Cars (which side has
more or fewer), Traffic Jam (count one colour in a mixed jam) and My Cars. Each game tracks what
Sonny John gets right first time and gets a little harder as he does.
